## Key Highlights & Features

### 1. Interactive DevOps Terminal Simulator (`devops-cli`)
- Authentic command-line interface directly in the browser with command history, autocomplete, and output rendering.
- Executable commands:
  - `help` &mdash; lists all available terminal commands.
  - `cat resume` &mdash; formatted terminal resume breakdown.
  - `terraform plan` &mdash; simulates AWS VPC, ECS Fargate & ALB infrastructure plan.
  - `kubectl get pods -A` &mdash; inspects active Kubernetes pods across namespaces.
  - `docker ps` &mdash; lists production container workloads.
  - `nexusml status` &mdash; checks MLOps model serving health and drift metrics.
  - `curl /metrics` &mdash; scrapes live Prometheus telemetry metrics.
  - `contact` &mdash; outputs direct contact channels.

### 2. Interactive NexusML Decision Boundary Sandbox
- Real-time HTML5 Canvas visualizer rendering mathematical 2D classification decision boundary fields.
- Switch between **Moons**, **Circles**, and **Linear** synthetic dataset topologies.
- Toggle between **Neural Network (MLP)**, **Random Forest**, and **Logistic Regression** classifiers.
- Click anywhere on the coordinate plane to test live simulated point inference with instant confidence scores and sub-5ms latency gauges.

### 3. Automated Cloud & MLOps Pipeline Architecture
- Complete 5-stage interactive lifecycle flowchart:
  1. **Code & Model Versioning** (Git & Scikit-Learn)
  2. **CI Quality Gate** (GitHub Actions, Pytest, Drift Validation)
  3. **Multi-Stage Containerization** (Docker, AWS ECR)
  4. **IaC Orchestration** (Terraform, AWS ECS Fargate, Kubernetes HPA)
  5. **Telemetry & Observability** (Prometheus, Grafana)

## Local Launch & Quickstart

Clone the repository and open `index.html` in your browser, or run a local HTTP server:

```bash
# Clone repository
git clone https://github.com/itachi-rdy79/portfolio.git
cd portfolio

# Run with any static server:
npx serve .
# or
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
